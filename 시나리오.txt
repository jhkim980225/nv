@startuml  거스름돈_동전

title 100페소 결제 → 200페소 지폐 투입 → 100페소 동전 거스름돈\n(SMART Coin 우선 지급)

actor "POS / 프론트엔드" as POS
participant "게이트웨이\n(:8001)" as GW
participant "ITL REST API\n(:5000)" as ITL
participant "NV4000\n(COM4)" as NV
participant "SMART Coin\n(COM3)" as COIN

== 1. 장치 연결 ==

POS -> GW: POST /device/connect
GW -> ITL: OpenConnection (NV4000-COM4)
GW -> ITL: OpenConnection (SMART_COIN_SYSTEM-COM3)
GW --> POS: {nv4000:{ok:true}, smart_coin:{ok:true}}

== 2. 결제 시작 ==

POS -> GW: POST /payment/start\n{target_amount:100, timeout_sec:120}
note over GW: 수락기 활성화\n(NV4000 + SMART Coin 동시)
GW --> POS: {tx_id:"abc123"}
POS -> GW: GET /payment/stream/abc123  ← SSE 구독

== 3. 200페소 지폐 투입 ==

NV -> ITL: STORED event (200페소)

loop 200ms 폴링 (게이트웨이 내부)
    GW -> ITL: GetDeviceStatus NV4000-COM4
    ITL --> GW: [{eventTypeAsString:"STORED", value:200페소}]
    note over GW: bill_amount = 200페소\ntotal(200) >= target(100) → COMPLETE\nchange = 100페소
end

== 4. 수납 차단 ==

GW -> ITL: DisableAcceptor (NV4000 + SMART Coin)
GW --> POS: SSE {status:"COMPLETE", total:200페소, change:100페소}

== 5. 동전 거스름돈 지급 (SMART Coin 우선) ==

GW -> ITL: EnablePayout SMART_COIN_SYSTEM-COM3
GW -> ITL: DispenseValue {Value:100페소}
ITL -> COIN: 동전 100페소 지급
ITL --> GW: {dispenseResult:"COMPLETED"}

GW --> POS: SSE {change_result:{result:"OK", device:"SMART_COIN", amount:100페소}}

== 6. 결과 확인 ==

POS -> GW: GET /payment/status/abc123
GW --> POS: {status:"COMPLETE", bill_amount:200페소,\nchange_amount:100페소,\nchange_result:{device:"SMART_COIN", result:"OK"}}

@enduml


@startuml  거스름돈_지폐

title 100페소 결제 → 200페소 지폐 투입 → 100페소 지폐 거스름돈\n(동전 부족 시 NV4000 리사이클러 폴백)

actor "POS / 프론트엔드" as POS
participant "게이트웨이\n(:8001)" as GW
participant "ITL REST API\n(:5000)" as ITL
participant "NV4000\n(COM4)" as NV
participant "SMART Coin\n(COM3)" as COIN

== 1~4. 결제 시작 ~ 수납 완료 (동일) ==

note over POS, COIN: 장치 연결 → 결제 시작 → 200페소 투입\n→ COMPLETE, change=100페소

== 5. 동전 거스름돈 시도 → 실패 ==

GW -> ITL: EnablePayout SMART_COIN_SYSTEM-COM3
GW -> ITL: DispenseValue {Value:100페소}
ITL -> COIN: 동전 지급 시도
ITL --> GW: {dispenseResult:"NOT_ENOUGH_VALUE"}  ← 동전 부족
note over GW: SMART Coin 실패\n→ NV4000 리사이클러 시도

== 6. 지폐 거스름돈 지급 (NV4000 폴백) ==

GW -> ITL: EnablePayout NV4000-COM4
GW -> ITL: DispenseValue {Value:100페소}
ITL -> NV: 리사이클러에서 100페소 지폐 지급
ITL --> GW: {dispenseResult:"COMPLETED"}

GW --> POS: SSE {change_result:{result:"OK", device:"NV4000", amount:100페소}}

== 7. 결과 확인 ==

POS -> GW: GET /payment/status/abc123
GW --> POS: {status:"COMPLETE", bill_amount:200페소,\nchange_amount:100페소,\nchange_result:{device:"NV4000", result:"OK"}}

note over POS: 동전 대신 지폐로 거스름돈 지급됨\n(리사이클러 2번 — 100페소)

@enduml
